音频文件夹
==========

现在里面放的是程序生成的雨声占位素材（32 秒、可无缝循环、单声道 32kHz）。
可以用你自己的录音直接替换，文件名保持不变即可，格式换成 mp3 也能用
（改 js/audio.js 里的 RAIN_FILE 后缀）。

雨声
----
rain-light.wav   细雨     —— 序、第二章、第五章多数室内段落
rain-mid.wav     中雨     —— 校门口、站台、等车
rain-heavy.wav   大雨     —— 深夜窗前
rain-storm.wav   暴雨     —— 纪念馆、全片最响的一场（P36）
rain-indoor.wav  隔着窗的雨 —— 电话、夜车车厢内
rain-door.wav    门外的闷雨 —— 开门时走廊那一下

音乐
----
bgm-01.mp3 ~ bgm-10.mp3（按章：0=序，1~9=第一到第九章）
现在没有这些文件，游戏会安静地跳过，不会报错。
做好了丢进来就自动响。

有关音量
--------
每一帧的雨量和音量写在 js/audio.js 的 RAIN 表里，单位是负数分贝，
例如 ["heavy", -18] 就是大雨、-18dB。改这个表就能微调全片的声音结构。

重新生成雨声
------------
python tools/make_rain.py
